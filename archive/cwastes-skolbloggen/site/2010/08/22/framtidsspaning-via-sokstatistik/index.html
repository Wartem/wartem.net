Framtidsspaning via sökstatistik

By cwaste | Published: 22 augusti, 2010

Läs artikeln på TV4 om hur våra sökningar kan användas att förutse den närmsta framtiden: Sökmotor kan förutsäga vinterkräksjukan.

Både spännande och läskigt tycker jag!

Att vi kan öka beredskapen när det behövs, för att bättre skydda oss mot virus, låter bra. Men …

Vilka fördelar och nackdelar kan dessa möjligheter innebära?
