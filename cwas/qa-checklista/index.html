QA

Manuell QA-checklista (sida för sida)

Använd denna sida som snabb genomgång före publicering eller efter större ändringar. Fokus är att handboken känns sammanhängande och går snabbt att använda.

Snabb QA

5–10 minuter: snabb kontroll

En kort runda som fångar de vanligaste regressionsfelen.

Snabb check

  • ✓ Fungerar startsidan och syns snabba startspår tydligt?
  • ✓ Fungerar intern sök (testa minst tre ord)?
  • ✓ Fungerar filtrering i Verktyg och Promptbibliotek?
  • ✓ Fungerar kopiera-knapparna i prompts?
  • ✓ Fungerar tillbaka-länkar och brödsmulor på vanliga sidor och verktygssidor?
  • ✓ Visas relaterat innehåll under sidan?
  • ✓ Ger 404-sidan tydliga vägar tillbaka?
Bra startpunkt Tips
Testa först Sök, Verktyg (filter) och Promptbibliotek (filter + kopiera).

Ordning

Sida för sida: rekommenderad QA-runda

Kör detta när du vill göra en lite grundligare kontroll.

QA-runda

  1. Start + Profil

    Kontrollera läsbarhet, länkar och att behovsbilden känns konsekvent.

  2. Arbetsflöden + Promptbibliotek

    Testa prompts, filtrering, kopiera och [KOLLA]/[OSÄKERT]-markeringar.

  3. Verktyg + Jämförelse

    Kontrollera verktygssidor, filtrering och betaljämförelsens länkar.

  4. Integritet + Tips + Sök

    Kontrollera checklister, sökresultat och navigation.

Innehåll

Innehållskontroll i praktiken

Det viktigaste är att användaren snabbt förstår vad som ska göras och vart man går vidare.

Vad du kontrollerar

KontrollpunktVad du letar efterÅtgärd om fel
SpråkKort, tydlig svenska och konsekventa ordvalKorta stycken, förenkla formuleringar, samordna rubriker
LänkarRätt sida/sektion öppnasRätta `href` eller ankare
Markeringar[KOLLA]/[OSÄKERT] finns där de behövsLägg till i workflows/prompts
PromptarKorta nog för gratisläge och tydliga nog att fungeraKortare instruktion, tydligare formatkrav
SammanhangSidan leder vidare till nästa stegLägg till relaterat innehåll eller intern länk
Viktigt för denna sajt Varning
Kontrollera särskilt workflows och prompts så att faktakoll- och osäkerhetsmarkeringar finns kvar där de behövs.

UX

UX och navigation

Sajten bygger på snabb orientering via sök, filter, relaterat innehåll och tydliga vägar tillbaka.

UX-checklista

  • ✓ Mobilmeny går att öppna och använda.
  • ✓ Filterknappar visar aktivt läge och går att använda med tangentbord.
  • ✓ Sök visar tomt läge när inget matchar.
  • ✓ Utskrift ser rimlig ut på minst en längre sida.
  • ✓ Footer länkar till rätt nyckelsidor.
Testa verkliga flöden Info
Exempel: Start → Arbetsflöden → Verktygssida → tillbaka → Sök → sektionsträff. Om det känns naturligt är UX-kedjan i bra skick.

Publicering

Inför publicering

Slutkontroller för build och innehåll när det är dags att publicera uppdateringar.

Publiceringscheck

  • ✓ Kör `npm install` och `npm run build` när nät/cache finns.
  • ✓ Klicktesta ett urval av sidor i build/preview.
  • ✓ Kontrollera att inga tillfälliga filer följer med.
  • ✓ Bekräfta 'Senast uppdaterad' om innehållet ändrats.
Miljön här Info
Build har tidigare varit blockerad av offline npm-cache. Kör lokal build när nät/cache finns tillgängligt.
