Passar för CWas

När ChatGPT brukar ge mest nytta

Sammanfattning utifrån källmaterialet: vilka typer av uppgifter verktyget hjälper bäst med i CWas skolbiblioteks-, politik- och studievardag.

Passar för CWas när behovet är...

  • ✓ Snabbt skriva om, förkorta eller strukturera texter under tidspress.
  • ✓ Debattträning och muntlig träning (särskilt om CWas vill använda dialog/röstläge).
  • ✓ Skapa arbetsplaner, utkast och mallar för återkommande uppgifter.
  • ✓ Språkstöd kring akademiska texter när målet är begriplighet och seminarieförberedelse.

Bedömning

Styrkor och svagheter

Fokus här är praktisk användbarhet för CWas, inte en generell "bäst i test"-rankning.

Styrkor

  • ✓ Bred användning: samma verktyg kan användas för skrivande, planering och dialogträning.
  • ✓ Starkt stöd för svensk text i vardaglig användning enligt källmaterialet.
  • ✓ Bra för iteration: utkast -> kritik -> ny version i samma tråd.
  • ✓ Kan fungera som träningspartner för tes, invändningar och 'håll linjen'-övningar.

Svagheter / begränsningar

  • ✓ Sämre än källfokuserade verktyg när du behöver tydliga källspår för research/faktakontroll.
  • ✓ Kan låta säker även när fakta är osäkra eller ofullständiga (hallucinationsrisk).
  • ✓ Kan bli för instämmande om du inte uttryckligen ber om friktion och kritik.
  • ✓ Funktioner/kvoter varierar mellan plan och kan ändras över tid.

Användning

När använda (och när välja något annat)

Snabbt stöd för att välja rätt verktyg i rätt läge, baserat på uppgift, tidsram och krav på kontroll.

Använd ChatGPT när...

  • ✓ Du behöver ett snabbt utkast, omskrivning eller strukturhjälp och vill arbeta vidare direkt.
  • ✓ Du vill debattträna med korta repliker, följdfrågor och feedback i samma verktyg.
  • ✓ Du vill skapa återanvändbara promptmallar för CWas vardag.
  • ✓ Du vill kombinera skrivstöd och reflektionsstöd i ett verktyg.

Välj annat verktyg eller arbetssätt när...

  • ✓ Du behöver tydlig källhänvisning som huvudfunktion (börja hellre i Perplexity).
  • ✓ Du arbetar med känsliga personuppgifter eller individärenden (använd inte extern molntjänst).
  • ✓ Du behöver lokal/offline hantering av dokument av integritetsskäl.

Kort rutin för säkrare användning

  1. Sätt uppgift och format

    Börja med mål, målgrupp, längd och tidsram. Var tydlig med att svaret ska vara på svenska.

  2. Kräv kontrollmarkeringar

    Be om [KOLLA] för faktapåståenden och [OSÄKERT] när underlaget inte räcker.

  3. Kör kritisk runda

    Be om tre svagheter, motargument eller risker innan du använder texten.

  4. Slutgranska själv

    CWas granskar ton, fakta och om texten faktiskt låter som CWas.

Integritet

Integritet i korthet

Kort, praktisk vägledning för CWas. För full rutin: se Integritet och GDPR.

Integritetsöversikt Varning
Behandla ChatGPT som en extern molntjänst. Använd datakontroller och undvik personuppgifter, elevärenden eller annat känsligt material. Om röst används: hantera mikrofonbehörighet aktivt.

Praktiska kontroller

  • ✓ Anonymisera namn, personnummer och individärenden före promptning.
  • ✓ Använd tillfällig chatt / datakontroller när innehållet är känsligare.
  • ✓ Ge mikrofonbehörighet bara när du faktiskt tränar med röst.
  • ✓ Separera retorikträning från känsliga sakuppgifter.
Faktakoll / verifiera i praktiken Info
  • Be alltid om markering av osäkra fakta med [KOLLA] eller [OSÄKERT].
  • Verifiera siffror, citat, datum och beslut i primärkällor innan publicering eller framförande.
Osäkert eller varierar mellan plan/inställningar Info
  • Vilka funktioner som ingår (t.ex. röst, kvoter, projektfunktioner) beror på plan och kan ändras.
  • Hur väl röstläge fungerar i praktiken beror på enhet, språk och inställningar.

Exempelprompts

Exempelprompts för ChatGPT

Dessa är startpunkter som kan klistras in och anpassas. Lägg alltid till eget underlag och markera faktakoll där det behövs.

Redaktör för politisk text

Du är min redaktör på svenska.
Hjälp mig göra texten tydligare och mer slagkraftig utan att ändra min ståndpunkt.

Gör detta:
1. Skriv om texten med tydligare struktur och mindre snömos.
2. Föreslå 5 rubriker och 2 ingresser.
3. Markera faktapåståenden med [KOLLA].
4. Markera sådant du antar med [OSÄKERT].
5. Lista 3 svagheter i texten och hur jag kan förbättra dem.

Text:
[klistra in]

Debattcoach (tes -> invändning -> förbättrat svar)

Du är min strategiska debattcoach på svenska.
Du får inte hålla med som standard.

Upplägg:
- Be mig säga min tes i 1 mening.
- Tvinga mig till en 20-sekunders pitch.
- Ge 2 rimliga invändningar (inte halmgubbar).
- Efter varje svar: ge kort feedback + bättre formulering som låter som mig.
- Markera faktapåståenden som behöver verifieras med [KOLLA].

Starta nu med: "Vilken tes vill du träna på?"

Akademiskt språkstöd inför seminarium

Jag ska presentera en akademisk artikel.
Arbeta bara utifrån texten/anteckningarna jag ger.

Gör detta på svenska:
1. 60-sekunders sammanfattning.
2. 3-minuters version med begrepp förklarade.
3. Ordlista (10 termer).
4. 5 möjliga seminariefrågör + korta svar.
5. Markera allt som inte framgår av underlaget med [OSÄKERT].
6. Markera uppgifter som bör kontrolleras i originaltexten med [KOLLA].

Underlag:
[klistra in abstract/anteckningar]
