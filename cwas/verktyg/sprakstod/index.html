Passar för CWas

När LanguageTool / Microsoft Editor brukar ge mest nytta

Sammanfattning utifrån källmaterialet: vilka typer av uppgifter verktyget hjälper bäst med i CWas skolbiblioteks-, politik- och studievardag.

Passar för CWas när behovet är...

  • ✓ Slutrunda på politiska texter, planer och dokument innan de delas/publiceras.
  • ✓ Snabb språkgranskning av svenska texter (stavning, grammatik, tydlighet).
  • ✓ När CWas vill förbättra läsbarhet utan att starta ett stort AI-flöde.
  • ✓ Som komplement till Claude/ChatGPT efter att innehåll och struktur redan är satta.

Bedömning

Styrkor och svagheter

Fokus här är praktisk användbarhet för CWas, inte en generell "bäst i test"-rankning.

Styrkor

  • ✓ Låg lärtröskel och snabb effekt i vardagen.
  • ✓ Bra för korrektur, språkriktighet och tydlighet i svenska texter.
  • ✓ Passar utmärkt som sista steg efter AI-utkast och egen redigering.
  • ✓ Minskar risken för småfel som drar ned trovärdighet.

Svagheter / begränsningar

  • ✓ Ger inte strategisk hjälp med tes, argumentation eller debattupplägg.
  • ✓ Är inte ett researchverktyg och faktakollar inte innehåll.
  • ✓ Förslag kan ibland ändra nyans/ton; CWas måste läsa varje ändring.
  • ✓ Klarar inte själv komplex omarbetning av innehållslig logik.

Användning

När använda (och när välja något annat)

Snabbt stöd för att välja rätt verktyg i rätt läge, baserat på uppgift, tidsram och krav på kontroll.

Använd LanguageTool / Microsoft Editor när...

  • ✓ Textens innehåll är klart men du vill förbättra språk och läsbarhet.
  • ✓ Du vill hitta småfel innan publicering eller inlämning.
  • ✓ Du behöver göra en text mer konsekvent i stil eller ton.
  • ✓ Du vill kombinera snabb AI-skrivning med säker slutgranskning.

Välj annat verktyg eller arbetssätt när...

  • ✓ Du behöver källor, research eller akademisk artikelöverblick.
  • ✓ Du behöver debattträning eller muntlig strategisk feedback.
  • ✓ Du vill få fram själva kärnbudskapet (använd först ett skriv-/dialogverktyg).

Kort rutin för säkrare användning

  1. Gör innehållsrundan först

    Sätt tes, struktur och sakinnehåll innan du börjar finputsa språket.

  2. Kör språkgranskning

    Granska stavning, grammatik och formuleringar – men acceptera inte allt automatiskt.

  3. Skydda rösten

    Behåll formuleringar som bär CWas ton även om verktyget föreslår mer standardiserat språk.

  4. Faktakolla separat

    Språkstöd ersätter inte faktakontroll. Kontrollera påståenden i källor efteråt.

Integritet

Integritet i korthet

Kort, praktisk vägledning för CWas. För full rutin: se Integritet och GDPR.

Integritetsöversikt Varning
Språkstöd är ofta lågtröskel och praktiskt, men text du klistrar in kan fortfarande behandlas av extern tjänst beroende på verktyg och miljö. Anpassa efter texttyp och känslighet.

Praktiska kontroller

  • ✓ Undvik att klistra in känsliga personuppgifter och individärenden.
  • ✓ Anonymisera namn om texten innehåller elevnära eller personkopplad information.
  • ✓ Använd lokal/offline lösning om integritetskravet är högt.
  • ✓ Kom ihåg att språkverktyg inte avgör vad som är lämpligt att dela.
Faktakoll / verifiera i praktiken Info
  • Språkstöd kontrollerar språk – inte sanningshalt. Faktakoll görs alltid separat.
  • Automatiska omskrivningar kan råka ändra betydelsen; kontrollera sakinnebörden.
Osäkert eller varierar mellan plan/inställningar Info
  • Vilka funktioner som finns beror på om du använder LanguageTool, Microsoft Editor eller annan integrerad variant.
  • Integritetsnivå varierar beroende på klient (webb, tillägg, lokal installation, organisationens miljö).

Exempelprompts för LanguageTool / Microsoft Editor

Dessa är startpunkter som kan klistras in och anpassas. Lägg alltid till eget underlag och markera faktakoll där det behövs.

Instruktion för AI före språkstöd (förbättra utan att ändra betydelse)

Gör en språkförbättringsrunda på texten nedan.

Krav:
- Ändra inte ståndpunkt eller sakinnehåll
- Behåll min ton så långt det går
- Gör språket tydligare och mer lättläst
- Markera meningar där omskrivning riskerar att ändra betydelsen med [KOLLA]

Leverera:
1. Förbättrad version
2. Lista över 5 känsliga formuleringar att läsa extra noga

Förenkla svenska utan att bli platt

- Behåll nyanser och saklighet
- Undvik att göra texten "PR-mjuk"
